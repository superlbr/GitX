本目录里的 `NotoSansSC-Regular.otf` **不入库**（8.3 MB，见根 `.gitignore`），
构建前按需重新取一份，从字体自身 `name` 表读到的授权声明：

> This Font Software is licensed under the SIL Open Font License, Version 1.1.
> This Font Software is distributed on an "AS IS" BASIS, WITHOUT WARRANTIES OR
> CONDITIONS OF ANY KIND, either express or implied. See the SIL Open Font
> License for the specific language governing permissions and limitations.
> http://scripts.sil.org/OFL

（以上三行是 `Noto Sans SC` 内嵌的 name ID 13 / 14，不是我们转述的。）

取一份完整的字体（raw.githubusercontent 在这台机器上只有 ~1 KB/s，jsDelivr 能跑满）：

```sh
cd gitcraft-app/assets/fonts
curl -L -o NotoSansSC-Regular.otf \
  https://cdn.jsdelivr.net/gh/notofonts/noto-cjk@main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf
```

拿到后应当是 **8 331 336 字节**；`src/fonts.rs` 里的 `complete()` 会校验 sfnt 表目录，
半截文件会被跳过并退回用户机器上的 CJK 字体——因为 epaint 解析失败是在不展开的闭包里
panic，那会让进程直接 abort。OFL 1.1 全文见 http://scripts.sil.org/OFL 。
